# ELEV8MI v27 verification

Focused browser checks cover continuous closed-perimeter nav motion, rounded
mobile menu behavior, text clearance, resizing, user pause and reduced motion.
Draw checks cover initial disabled cards, style activation, one/three-card
selection, unique picks, controls, authentic card art, reset, centered dialog
and the exact mailto draft. Mobile orbital bounds and separation are checked
over simulated motion and the broad perspective view is visually reviewed.
Package validation checks source/ZIP byte matching, assets, JavaScript syntax,
embedded preview integrity, favicon exports and share metadata/image dimensions.

Existing v26 Earth/weather rendering was preserved; its desktop/mobile,
sky-phase and CPU-fallback verification is documented in the v26 package.
Device performance controls actual frame rate. Reduced motion uses still imagery.
Celestial speeds, sizes, camera framing and light intensities are artistic.
